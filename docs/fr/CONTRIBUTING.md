# Contribuer

Merci de proposer des changements ciblés et accompagnés d’une vérification.

```bash
npm ci
npm test
npm run build
```

Pour un changement d’interface, tester au minimum la galerie, une fiche avec
plusieurs variantes, une progression, la carte du ciel et `/admin` en desktop
et à 390 × 844 px. Aucun jeu de données personnel, index Astrometry.net, résultat
WCS ou image finale volumineuse ne doit être ajouté au dépôt.

Les nouvelles métadonnées d’exemple doivent rester synthétiques ou disposer
d’une licence explicitement compatible. Documentez tout nouveau champ dans
`DATA_MODEL.md`.
